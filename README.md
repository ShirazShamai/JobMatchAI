# JobMatchAI

פרויקט Python להשוואה בין קורות חיים לתיאור משרה.

## גרסה 1

הגרסה הראשונה מתוכננת לקרוא שני קובצי טקסט ולהציג בטרמינל ציון התאמה, כישורים תואמים, כישורים חסרים והצעות לשיפור, על בסיס רשימת כישורים מוגדרת מראש.

בשלב הנוכחי קיימים רק שלד הפרויקט וקובצי דוגמה. לוגיקת ההשוואה עדיין לא מומשה.

הפרויקט ישתמש ביכולות המובנות של Python, ללא מסד נתונים, ממשק frontend, אימות משתמשים או חיבור ל־AI API חיצוני.

## מבנה הפרויקט

- main.py: נקודת ההפעלה העתידית של התוכנית.
- matcher.py: לוגיקת ההשוואה וחישוב התוצאות בעתיד.
- skills.py: רשימת הכישורים לזיהוי בעתיד.
- data/resume.txt: קורות חיים לדוגמה.
- data/job_description.txt: תיאור משרה לדוגמה.
